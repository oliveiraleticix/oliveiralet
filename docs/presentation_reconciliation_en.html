How it works

End-to-end daily flow

1. Daily Job runs the notebook in Databricks

2. SQL compares debit/credit by account

3. Status: ✅ no differences / ⚠️ differences found

4. Automatic Slack notification

Default date rule

Empty run_date = second prior business day, including weekends + BR national holidays.

Security

Webhook stored in Databricks Secrets.

Output

What the Slack message contains

  • Entity and processing date
  • Monitored accounts (Calypso/SAP)
  • Accounts with activity / without activity
  • Accounts with differences + net sum
  • Differences by account (prioritized)
